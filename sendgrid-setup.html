📋 How to Get Your SendGrid API Key

  1. Sign up/Login to SendGrid:
    Go to sendgrid.com and create an account or log in
  2. Navigate to API Keys:
    Dashboard → Settings → API Keys
  3. Create API Key:
    Click "Create API Key" button
  4. Set Permissions:
    Choose "Full Access" or "Restricted Access" with Mail Send permissions
  5. Copy the Key:
    Copy the generated key (starts with "SG.") - you won't see it again!
  6. Verify Sender Identity:
    Go to Settings → Sender Authentication and verify your email domain
⚠️ Important: Store your API key securely. SendGrid will only show it once!
